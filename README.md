# HybridNutrientModel

Description of scripts.

Script_Z_Nutrients_first.py: Merging TP monitoring data with TP simulation data from IMAGE-GNM

Script_Z_Nutrients_second.py: Training and saving the random forest model for TP

Script_Z_Nutrients_third.py: Applying the hybrid model (without mass balance) for the historic period 1980-2010 and TP

Script_Z_Nutrients_fourth.py: Merging TN monitoring data with TN simulation data from IMAGE-GNM

Script_Z_Nutrients_fifth.py: Training and saving the random forest model for TN

Script_Z_Nutrients_sixth.py: Applying the hybrid model (without mass balance) for the historic period 1980-2010 and TN

Script_Z_Nutrients_seventh.py: Applying the hybrid model (without mass balance) for the period 2010-2015 and TP

Script_Z_Nutrients_eighth.py: Applying the hybrid model (without mass balance) for the period 2010-2015 and TN

Script_Z_Nutrients_ninth.py: Applying the hybrid model (without mass balance) for the period 2015-2100 and TP

Script_Z_Nutrients_tenth.py: Applying the hybrid model (without mass balance) for the period 2015-2100 and TN

Script_Z_Nutrients_Z.py: Applying mass balance constraint for historic period (1980-2010) and TP

Script_Z_Nutrients_Z2.py: Applying mass balance constraint for period 2010-2015 and TP

Script_Z_Nutrients_Z3.py: Applying mass balance constrain for period 2015-2070 and TP

Script_Z_Nutrients_Z4.py: Applying mass balance constrain for historic period (1980-2010) and TN

Script_Z_Nutrients_Z5.py: Applying mass balance constraint for period 2010-2015 and TN

Script_Z_Nutrients_Z6.py: Applying mass balance constraint for period 2015-2070 and TN

Script_Z_Z_Z_P.py: Combining the hybrid outputs for 2010-2015 and 2015-2070 for TP

Script_Z_Z_Z_N.py: Combining the hybrid outputs for 2010-2015 and 2015-2070 for TN
